# Urban Survival Google Play 등록 문안 초안

- 작성일: 2026-10-06 (초안, 사용자가 검토·수정 후 Play Console에 입력)
- 앱 이름: **Urban Survival** (Play 앱 이름 제한 30자 이하)
- 패키지명: `com.yws.urbansurvival` / 개발자: YWS
- 아래 문안은 현재 게임에 **실제로 있는 기능만** 적었다. 기능을 바꾸면 문안도 맞춰 고친다.

## 1. 사실 확인(문안의 근거)

- 탑뷰·쿼터뷰 PC/모바일 싱글 플레이 좀비 생존 슈터. 광고·인앱 결제·계정·온라인 기능 없음(코드 검색 결과 네트워크 사용 0건).
- 캐릭터 2종(A/B, 능력치 배율이 다름), 무기 4종(권총, 소총(AR), SMG, 산탄총). 권총은 기본 무기이고 나머지는 적 처치 드랍으로 획득.
- 적: 일반, 빠른 적, 강화 적, 보스(10분마다 등장). 30분 생존 후 30분 보스를 처치하면 결과 화면에서 "무한 모드" 진입 여부를 고른다. 시간이 지날수록 적이 강해진다.
- 드랍: 무기, 탄약, 회복 상자. 보스 연습(PRACTICE) 모드 있음.
- 모바일 조작: 가상 이동 스틱, 자동 조준 + FIRE 버튼 또는 쌍둥이 스틱(직접 조준), 재장전 버튼, 무기 선택 버튼. 가로 화면 전용. 설정에서 볼륨·그래픽 품질·조준 방식 변경.
- UI는 영어, 튜토리얼은 한국어. 음악·효과음 포함.

## 5. 콘텐츠 등급 설문 가이드 (IARC)

설문은 사실대로 답한다. 이 게임 기준 답변 방향:

- 폭력: **있음**. 사람 모양의 군인이 좀비(상상 속 괴물)를 총으로 쓰러뜨린다. 혈흔 표현이 있다. 실사가 아닌 로우폴리 스타일.
- 사람 대상 폭력: 플레이어 캐릭터가 좀비에게 맞아 쓰러진다. 좀비는 인간형 괴물이다.
- 성적 콘텐츠·욕설·도박·약물: 없음.
- 사용자 간 상호작용·위치 공유·개인정보 공유·디지털 구매: 없음.
- 예상 결과: 폭력 표현 때문에 어린이 등급이 아닌 청소년(예: Teen / 12+ 또는 15+) 등급이 나올 가능성이 높다. **최종 등급은 IARC 결과를 따른다.**

## 6. 데이터 보안(Data safety) 양식 가이드

답변은 Unity Analytics 사용 여부에 따라 달라진다. **2026-10-06 사용자 결정으로 Analytics를 껐다(`df2d3f4`) → 시나리오 A로 작성한다.** **확정(2026-10-07):** Analytics를 꺼도 Unity가 `INTERNET`을 넣어서 `a0fd5e6`(커스텀 런처 매니페스트)로 제거했고, 업로드용 AAB(`ab09266` 기준)에서 **요청 권한 0개**를 확인했다. 데이터 수집 아니오·공유 아니오로 답한다. 권한이 남아도 게임 코드는 네트워크를 쓰지 않으므로 "수집 없음"은 유지되지만, 패키지(`com.unity.analytics`)가 데이터를 보내지 않는지 확인되기 전까지는 패키지 제거도 검토한다.

**시나리오 A — Unity Analytics를 끈 경우(권장, 신고 부담이 작음)**
- 데이터 수집: 아니오, 데이터 공유: 아니오.
- 이유: 게임이 저장하는 값은 설정·조준 모드·튜토리얼 확인 여부·연습 최고 기록뿐이고 `PlayerPrefs`에 기기 안에만 저장한다. 계정·광고·결제·네트워크 통신이 없다.
- 전송 중 암호화/삭제 요청 항목: 수집이 없으므로 해당 없음 쪽으로 답한다(양식 안내에 따름).

**시나리오 B — Unity Analytics를 켠 채 출시하는 경우**
- 데이터 수집: **예**. Unity가 시작 시 보내는 기본 분석 데이터에 해당하는 항목(예: 기기 또는 기타 ID, 앱 활동/진단 등)을 **Unity 공식 문서에서 현재 수집 항목을 확인해** 신고한다. 신고 항목은 이 문서가 추측하지 않는다.
- 개인정보처리방침에 Unity Analytics를 명시한다(아래 7장 B 문구).
