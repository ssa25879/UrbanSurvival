# 기획서 21·22장 대조표 (F01~F16, I01~I09)

작성일: 2026-09-29. 기준: 기획서 v1.3 로컬 사본(2026-09-29), 코드 `SideProject` 브랜치 `96fa5e9` 이후 작업 트리.
검증 상태 표기: **검증** = Play Mode 등에서 실제 값을 확인함(작업 노트 기준) / **코드확인** = 코드를 읽고 동작이 맞다고 판단했으나 실행 확인은 안 함 / **미구현** / **불일치** = 기획서와 구현이 다름 / **빌드필요** = 독립 실행 빌드에서만 확인 가능.
이 문서는 에디터 없이 코드와 노트만 읽고 작성했다. "코드확인" 항목은 실행해서 재현한 결과가 아니다.

## 보스·1차 목표 (2026-09-29 구현, Play Mode 확인)

- 보스: 10분마다 1마리(무한 모드에서도 계속), 체력 기준 10·20분 300 / 30분 이후 600, 동시 500마리 상한과 무관하게 소환. 상단 중앙 큰 체력바와 머리 위 작은 바를 화면 렌더로 확인.
- 1차 목표: 30분 보스를 처치할 때 달성(이전에는 30분 경과). 일반 보스 처치는 목표가 아님, 30분 보스 처치 시 배너·스냅샷·점수(500+1000) 확인, 두 번째 30분 보스 처치는 무시됨.
- 확인 못 함: 실제 10분·30분 경과 스폰(경과 시간은 큐에 직접 넣어 검증), 보스 전투 체감, 좁은 통로에서 큰 보스의 이동.
- 좀비 색 버그(2026-09-29 수정): `Zombie`가 색을 적용하는 렌더러가 몸이 아니라 핏방울 파티클이라 2026-09-23 모델 교체 이후 Fast(빨강)·Heavy(검정) 틴트가 몸에 적용되지 않았다. 이제 모든 좀비의 몸(SkinnedMeshRenderer)에 재질 원래 색을 곱하고(`skinColor`) 필요하면 발광색을 더해(`glowColor`) 적용한다. 사용자 결정(2026-09-29)에 따라 기본 좀비는 현재 외형 유지(흰색), Fast는 붉은 빛 추가(곱 1, 0.38, 0.38 + 발광 0.16, 0, 0), Heavy는 검은 빛 추가(곱 0.42, 0.42, 0.45, 초록 기운이 남는 어두운 색), 보스는 붉은 갈색. 핏방울 파티클에는 더 이상 색을 적용하지 않는다. 초록 몸에 빨강을 곱하거나 더하기만 하면 갈색·주황으로 보여서 두 값을 함께 조정했다.

## 기획서와 구현이 다른 곳 (기획서 갱신 후보)

1. **HUD 위치(12장)**: 기획서는 좌하단 체력·우하단 총기·상단 중앙 웨이브. 실제는 좌상단 점수·체력·웨이브, 우하단 총기, 우상단 위협 미니맵.
2. **남은 적 표시**: 기획서는 총합(개발 HUD는 생존/대기 분리). 실제 HUD는 "살아있는 수 + 대기 수"(2026-09-29 사용자 결정).
3. **캐릭터 선택(12장)**: 인트로 START 뒤 선택 패널로 구현(외형 동일, 유니폼 색만 구분). 기획서는 외형 2종 선정.
4. **일시정지·결과 화면의 "선택 화면으로 돌아가기"**: 2026-09-29 구현. 일시정지 메뉴의 SELECT는 "현재 판이 종료됨"을 확인하는 패널(CANCEL/LEAVE)을 거쳐 인트로의 캐릭터 선택 패널로 이동, 결과 화면의 SELECT는 바로 이동. Play Mode에서 확인 패널 열기·취소, 일시정지 해제 시 확인 패널 닫힘, 결과 화면 버튼 3개 배치, 인트로에서 선택 패널이 바로 열리고 플래그가 한 번만 쓰이는 것을 확인(실제 마우스 클릭과 씬 전환 후 첫 프레임은 미확인).
5. **웨이브 완료 보너스(× 200점)·강화 적 250점·정비 대기·준비 5초·상태머신(14장)**: 구현에 없음. 점수는 모든 좀비 100점 고정.
6. **에셋(18장)**: 기획서 본문의 Downtown City MegaKit·Universal Base Characters·Ultimate Guns Pack은 실제로 쓰지 않음. 실제는 Toon Shooter Game Kit(환경·플레이어·무기), Zombie Apocalypse Kit(적). AGENTS.md가 우선.
7. **성능 목표(22장)**: "14마리 전투 60초" 기준을 동시 500마리 상한 도달 후 60초로 재정의(기획서 v1.7, 2026-09-29). 이 환경에서는 에디터가 백그라운드일 때 Play Mode 프레임이 진행되지 않아 프레임 시간은 측정하지 못했다. 확인한 것: 500마리 상한 유지(추가 소환 대기열 유지), 500마리 소환에 330 ms, 전부 NavMesh 위에 배치.
8. **폴더 구조(18장 `Assets/Game` 아래 Scripts 등)**: 실제 스크립트는 `Assets/Scripts`, 데이터는 `Assets/ScriptableData`.
