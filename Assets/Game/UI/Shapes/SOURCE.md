# UI 기본 도형 출처

- **이 프로젝트에서 직접 만든 이미지**(2026-10-07, 세션 2). 외부 에셋이 아니므로 별도 라이선스 조건이 없다.
- 목적: GUI PRO Kit(유료 Asset Store 에셋)의 흰색 기본 도형 3개를 대체해 빌드에서 GUI PRO를 빼기 위함(사용자 지시 "마저 정리").
- 만든 방법: 수식으로 그린 흰색 도형(8×8 슈퍼샘플링 안티에일리어싱). 기존 화면과 같게 보이도록 크기와 모양 값을 기존 이미지에 맞췄다(알파 평균 차이 0.2~0.65 / 255).

| 파일 | 크기 | 모양 | 9분할 경계(L,B,R,T) | 대체한 GUI PRO 이미지 |
|---|---|---|---|---|
| `UI_RoundRect_White.png` | 74×74 | 슈퍼타원(n=2.64) 둥근 사각형 | 37,37,37,37 | `BasicFrame_Rectangle02_s_White` |
| `UI_Line_White.png` | 60×6 | 양 끝 반원(반지름 3) 막대 | 30,0,30,0 | `LineFrame_White` |
| `UI_Circle_White.png` | 337×336 | 슈퍼타원(n=2.16) 원 | 없음 | `BasicFrame_Circle_337_White` |

- 게임에서는 `Image.color`로 색을 입힌다(어두운 패널, 앰버, 회색 등).
