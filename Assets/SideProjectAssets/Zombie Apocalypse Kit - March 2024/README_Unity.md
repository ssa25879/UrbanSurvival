# Zombie Apocalypse Kit — Unity 사용 안내

- 출처: https://quaternius.com/packs/zombieapocalypsekit.html
- 라이선스: CC0 1.0. 제공된 License.txt를 원문 그대로 보존했습니다. 파일 상단의 다른 팩 이름은 배포본 자체에 있는 표기입니다.
- Characters/FBX, Environment/FBX, Vehicles/FBX, Weapons/FBX: Unity용 원본 FBX 60개입니다.
- Characters/FBX의 Zombie_Basic, Zombie_Arm, Zombie_Chubby, Zombie_Ribcage가 좀비 4종입니다.
- Materials: 원본 FBX의 재질 이름, DiffuseColor와 텍스처 연결을 읽어 만든 프로젝트용 URP/Lit 재질입니다. 각 FBX의 Import Settings에서 재질을 연결했습니다.
- 캐릭터는 Generic 애니메이션으로 가져오며 포함 클립은 모델을 펼쳐 확인할 수 있습니다. Animator Controller, AI 및 충돌체 연결은 실제 게임 적용 시 별도로 진행합니다.
- Source~: Blender/OBJ/glTF 대체 원본을 보존한 폴더입니다. Unity 자동 임포트 대상에서는 제외하여 중복 모델과 Blender 의존성을 피합니다.
- 모델은 Project 창에서 FBX를 씬으로 드래그하여 사용할 수 있습니다. 게임용 수정은 프로젝트 전용 프리팹/변형본에서 진행하세요.
- 기존 플레이 씬과 Zombie 프리팹을 교체하지 않았습니다.
- 파일과 재질 참조의 정적 검증을 수행했습니다. Unity 에디터 내 표시 및 애니메이션 재생은 별도 확인이 필요합니다.
